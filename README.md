# Pi Workflow

基于Pi构建个人的工作流

## Pi 扩展

- **[Session Auto Name](pi-extensions/session-auto-name/README.md)**: 根据首次用户提示词自动命名 Pi 会话，并在首轮回复后按需完善名称。
- **[Warp Status](pi-extensions/warp-status/README.md)**: 在 Warp 标签栏显示 Pi 的运行状态，并在任务结束或需要人工操作时发送通知。

## Skills

- **[Dev Workflow](skills/dev-workflow/README.md)**: 提供 `pw-spec` 和 `pw-impl`，从需求对齐、spec 与 tickets 审阅，到 worktree 中的实现、验收与代码提交。

## Tools

- **[Pi Warp Delegate](tools/pi-warp-delegate/README.md)**: 在 Warp 新标签页中启动独立、可交互的 Pi 会话执行委派任务，并查询子会话主动上报的任务状态。
